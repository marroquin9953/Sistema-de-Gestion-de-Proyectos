Se desarrolló una aplicación web utilizando Next.js y React para la gestión de proyectos y tareas. La aplicación incluye autenticación de usuarios mediante JWT, manejo de roles, y un sistema de gestión de proyectos con una interfaz moderna desarrollada con Tailwind CSS.

El backend fue implementado con Node.js y Express.js, utilizando MySQL como base de datos. Se integraron herramientas como bcrypt para encriptación de contraseñas, nodemailer para envío de correos, y Swagger para documentar la API.

El proyecto se desplegó en Vercel, asegurando accesibilidad y facilidad de actualización. Se utilizó GitHub para el control de versiones y colaboración en equipo.
